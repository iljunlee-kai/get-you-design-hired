# 직군 정의 (roles.md)

규칙 버전: v0.22

이 도구는 디자인 직군 4개에 맞춰져 있다: **프로덕트 디자이너, 콘텐츠 디자이너, BX 디자이너, 브랜드 디자이너**. 정의는 한국 채용 공고의 실제 쓰임을 기준으로 했다(2026-10-25, 공고 본문 확인 목록은 맨 아래). 회사마다 같은 이름을 다르게 쓰므로 **공고 제목이 아니라 JD의 주요업무로 직군을 판정**한다.

## 공통 규칙

- 사용자가 고른 직군은 모두 목표 직군이다. 현재 직무와 같은 직군이어도 감점하지 않는다.
- 4개 직군 모두 포트폴리오 제출이 사실상 필수이고, **프로젝트별 본인 역할·기여도 표기**를 요구하는 공고가 많다. 링크가 아닌 PDF 제출을 요구하는 공고도 흔하다.
- 직군끼리 겹친다. 특히 BX와 브랜드는 경계가 흐리다. 한 공고가 두 직군에 걸치면 주요업무에서 비중이 큰 쪽으로 판정하고, 애매하면 "BX/브랜드"처럼 둘 다 적는다.
- 범위 밖 직군(서비스 기획, PM, 영상 PD 등)을 원하면 막지 않고 `messages.md`의 role_scope_note를 한 줄 보인다.

## 프로덕트 디자이너

- **하는 일**: 앱·웹 서비스의 사용자 경험과 화면 설계(UX/UI), 화면 디자인(GUI), 프로토타입, 디자인 가이드·시스템, 서비스 운영 개선.
- **검색어**: 프로덕트 디자이너, Product Designer, UX/UI 디자이너, UI 디자이너, UX 디자이너
- **판정 신호(주요업무)**: 사용자 조사·데이터 기반 개선, 플로우·와이어프레임, 프로토타이핑(Figma, ProtoPie), 디자인 시스템, 개발 협업, 서비스 개선
- **제외(노이즈)**: 웹디자이너(홈페이지 제작·퍼블리싱 중심), 산업·제품 디자이너(하드웨어), UX 리서처 전담
- **포트폴리오에서 볼 것**: 문제 → 과정 → 결과 흐름, 화면 흐름 설계, 리서치·지표 근거, 본인 기여도

## 콘텐츠 디자이너

- **하는 일**: 한국 시장에서는 범위가 넓다. 다수는 마케팅·커머스 콘텐츠(SNS 콘텐츠, 상세페이지, 프로모션·배너, 썸네일, 광고 소재)이고, 일부 회사는 서비스 문구 설계(UX 라이팅)를 콘텐츠 디자인이라 부른다.
- **하위 유형** (JD로 판정해 공고 표의 직군 칸에 괄호로 적는다):
  - 마케팅·커머스형: 상세페이지, 프로모션, 배너, SNS, 광고 소재, CTR·전환 같은 성과 지표로 개선
  - UX 라이팅형: 서비스 문구, 보이스앤톤, 에러·안내 메시지, 문구 가이드
- **검색어**: 콘텐츠 디자이너, 컨텐츠 디자이너, 콘텐츠 디자인, 상세페이지 디자이너, SNS 콘텐츠 디자이너, UX 라이터
- **제외(노이즈)**: 영상 PD·콘텐츠 프로듀서(촬영·편집 중심), 콘텐츠 마케터(디자인 업무 없음), 원고·블로그 작성
- **포트폴리오에서 볼 것**: 채널별 결과물, 성과 지표(CTR, 전환), 빠른 반복 사례, (UX 라이팅형) 문구 전후 비교

## BX 디자이너

- **하는 일**: 브랜드 경험 설계. 브랜드 아이덴티티(BI) 구축, 가이드라인·매뉴얼, 브랜드 에셋(로고·컬러·폰트) 일관성 관리, 온오프라인 접점(패키지, 굿즈, 프로모션, 공간, 웹)의 방향 설계, 신규 브랜드 런칭.
- **검색어**: BX 디자이너, BX디자인, 브랜드 경험 디자이너, BI 디자이너, BI/BX
- **판정 신호(주요업무)**: BI 구축, 브랜드 가이드라인, 브랜드 전략·디자인 방향 설정, 런칭부터 운영까지, 접점 전반 디렉팅
- **연차**: 확인한 공고 3건이 모두 5년 이상(5년+, 5~10년, 10년+)을 요구했다. 주니어 공고는 드물 수 있으니 연차 우선 규칙(±2년)으로 후보가 크게 줄면 개수와 이유를 리포트에 적는다.
- **포트폴리오에서 볼 것**: 주도한 브랜딩 프로젝트(전략 → 아이덴티티 → 적용), 가이드라인 산출물, 본인 기여도

## 브랜드 디자이너

- **하는 일**: 정해진 브랜드 안에서 그래픽·캠페인·프로모션·패키지·인쇄물을 만들고 운영한다. BX보다 실행·제작 비중이 크다.
- **검색어**: 브랜드 디자이너, 인하우스 브랜드 디자이너, 브랜딩 디자이너, 패키지 디자이너, 그래픽 디자이너(브랜드)
- **판정 신호(주요업무)**: 캠페인·프로모션 그래픽, 패키지(단상자, 라벨, 칼선, 후가공, 감리), 굿즈, 인쇄물, 오프라인 행사물
- **제외(노이즈)**: 출판 편집 디자이너, 광고대행사 AE
- **포트폴리오에서 볼 것**: 브랜드 일관성을 지킨 적용 사례, 패키지·인쇄 제작 경험, 결과물 완성도

## 직군을 넓게 답했을 때 (예: "디자이너", "디자인 쪽")

- 4개 중에서 고르게 한다. 후보는 대화에서 사용자가 직접 한 말이 있는 직군만, 근거 한 줄과 함께 낸다 (`questions.md`의 Q1 이후 처리).
- 사용자가 "알아서"라고 하면 에이전트가 해석해 `search_roles`에 넣고 근거(대화 번호)를 붙인 뒤, 프로필 블록에서 `messages.md`의 role_interpret_check로 확인받는다.
