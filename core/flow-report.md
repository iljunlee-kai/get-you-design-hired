# 단계 3: 리포트·재실행 (flow-report.md)

규칙 버전: v0.16

`START.md` 흐름의 단계 3이다. 섹션 번호(§)는 원래 지침 번호를 그대로 쓴다. 다른 파일의 "§N"은 `START.md`의 표에서 위치를 찾는다.

## 8. 리포트 (DOCX)

`report.md`의 구성·표·규칙을 따른다. 핵심만 적는다.

- 작성 전에 **"본인 답변 vs 대화 패턴" 대조표**를 먼저 만들고 리포트에도 싣는다. 서류가 있으면 자소서·이력서의 주장도 같은 표에 넣는다.
- 서류가 있으면 **서류 점검** 표를 쓴다: 서류에 쓴 주장 중 대화와 어긋나 면접에서 흔들릴 수 있는 것 1~3개 (`report.md` 2-3). 대화 번호 근거가 없으면 쓰지 않는다.
- 장점·단점 각 3개 이상(근거가 부족하면 있는 만큼), 맹점 1~3개. 모든 항목에 **근거(대화 번호)와 태그**.
- 근거가 2개 이상이면 `[추정]`을 쓰지 않는다. 확정 프로필의 강점·약점은 빠짐없이 반영한다.
- **방향 라벨**: 총평에 "대화에서 보이는 당신은 ~한 사람이에요"를 1~2개 쓰고, 이어지는 직업·직군 추천(선택 직군 밖의 탐색 후보 1개 포함 가능)을 근거와 함께 붙인다. 라벨마다 대화 번호 2개 이상과 태그를 쓰고 "이렇게 보여요, 맞나요?"로 제시한다. 사용자 반응은 `portrait`에 반영하고, 기각된 라벨은 같은 근거로 다시 쓰지 않는다. MBTI식 표현은 쓰지 않는다.
- 공고는 표로 쓰고 반복 문구를 쓰지 않는다.
- 3일 투두는 1~3위 공고에 연결한다. **1일차**에는 지원 전에 확인할 수 있는 것(마감, 지원 방법, 요건)을 확인하는 행동과, `interview_checks`를 **면접에서 물어볼 질문 2개**로 바꿔 넣는다. 공고로 확인할 수 없는 연봉·야근을 확인하라고 시키지 않는다.
- 표 앞에 **총평 3줄**을 쓴다: 대화에서 읽은 방향, 그 방향과 추천 상위 공고가 맞는지, 가장 먼저 할 일. 방향과 상위 공고가 어긋나면 이유를 한 줄로 설명한다.
- 푸터는 지정 문구 하나를 마지막에 한 번만 쓴다. 페이지마다 반복하지 않는다.
- 리포트에 **1~3위 요건 매칭표**를 넣는다 (`report.md` 4-1). 이 표가 지원 전략의 재료다.
- 채팅 최종 답변 순서: 파일 링크 → TOP 3 → 확인 줄(`START.md` 꼭 지킬 것 11) → **커리어 파일 블록(§10)** → **마지막 줄은 strategy_offer**. strategy_offer 없이 끝내지 않는다 (지원 전략 단계로 가는 유일한 입구다). 1~3위가 3개 미만이면 jd_paste_request를 한 줄 덧붙인다. 경고성 단락을 붙이지 않는다.

## 9. 재실행

리포트 전달 후 `messages.md`의 strategy_offer를 한 번 보이고 멈춘다. 회사를 고르면 단계 5(`core/flow-strategy.md`)로 간다. 조건을 바꿔 다시 찾고 싶다고 하면 프로필 블록만 고쳐 §5(공고 검색)부터 다시 한다.
